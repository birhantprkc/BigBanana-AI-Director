## BigBanana AI Director とは

**BigBanana AI Director（中国語名：大香蕉 AI 漫劇工場）** は、**AI 一站式の短編ドラマ／モーションコミックプラットフォーム**です。アイデアから完成動画までを高速に制作したいクリエイター向けに設計されています。

従来の「ガチャ」的な生成手法を捨て、**「脚本 -> アセット -> キーフレーム」** という産業用ワークフローを採用しています。AntSK API の先進的な AI モデルを深く統合することで、**「一文で完全な短編ドラマを生成し、脚本から完成動画までを全自動化」** しつつ、キャラクターの一貫性、シーンの連続性、そしてカメラワークの精密な制御を実現しました。

### 解決する核心的な課題

AI モーションコミック最大の痛点は、画質でも吹き替えでもなく、**キャラクターの一貫性**です。カットが変わると顔が変わり、視聴者は瞬時に物語から醒めてしまいます。BigBanana はこの課題に正面から向き合うために設計されました：**まず俳優とセットを用意し、それから撮影を始める。**

## 他の AI モーションコミックツールとの違い

| 比較軸 | 一般的な AI ツール（Kling／Jimeng など生成特化型） | BigBanana AI Director |
|--------|---------------------------------------------------|------------------------|
| **位置づけ** | 画像／動画生成の中核、単一画像または単一クリップ | 産業用フルパイプライン制作ワークベンチ |
| **キャラクター安定性** | 生成ごとに顔が変わりやすい | キャラクターシート＋ワードローブ＋コンテキスト認識の三重拘束 |
| **作業方式** | 単一画像／単一クリップ生成が中心 | 脚本 → アセット → キーフレーム → 完成動画の一体型フロー |
| **動画制御** | テキスト記述に依存し不安定 | 開始／終了キーフレームで画面を明確化し、中間をモデルが補間 |
| **シーン連続性** | 連続性の保証が困難 | シーンコンセプトで光とスタイルを統一、アセットを話数跨ぎで再利用 |
| **出力の位置づけ** | SNS での素早い共有向け | Premiere／Resolve などプロのポストプロダクションに接続可能 |
| **データ処理** | クラウドアップロードに依存しがち | ローカルブラウザ保存でプライバシーに配慮 |
| **自動化度** | 高い（ただし制御性は低い） | 中〜高（手動調整が必要、制御性は最高クラス） |

> 一文でまとめると：**BigBanana は最も自動化された AI モーションコミックツールではありませんが、最も制御しやすいツールの一つです。**

## 核心理念：キーフレーム駆動（Keyframe-Driven）

従来の Text-to-Video は、具体的なカメラワークや開始／終了画面の制御が困難でした。BigBanana はアニメーション制作の **キーフレーム（Keyframe）** 概念を導入しています：

1. **先に描き、後で動かす**：正確な開始フレーム（Start）と終了フレーム（End）を先に生成します。
2. **補間生成**：Veo モデルで 2 フレーム間の滑らかな動画遷移を生成します。
3. **アセット拘束**：すべての画面生成は「キャラクターシート」と「シーンコンセプト」によって強く拘束され、人物の崩れを防ぎます。

### キャラクター一貫性の三重保証

これが BigBanana の中核競争力であり、AI モーションコミックが連載できるかどうかを決める鍵です：

| 仕組み | 役割 |
|--------|------|
| **第一重：キャラクターシート** | 各キャラクターの標準参照画像を生成し、全編の視覚アンカーとします。以後のすべてのカット生成がこの「顔」を参照します。 |
| **第二重：ワードローブシステム** | 同一キャラクターに複数の衣装（日常着、戦闘服、負傷状態など）を設定可能。すべてのバリエーションは Base Look を基に生成され、顔の特徴を保ちます。**服を変えても人は変わらない。** |
| **第三重：コンテキスト認識生成** | カット生成時に現在のシーン画像、キャラクターの衣装参照、小道具参照を自動的に読み込みます。ゼロからではなく、直前の物語を「知っている」状態で生成します。 |

## コア機能モジュール

### プロジェクトレベルワークフロー

* **プロジェクトハブ**：最近のプロジェクト、アカウント入口、モデル設定、グローバルアセットライブラリ、ライブラリ全体のインポート／エクスポートを一元管理します。
* **プロジェクト概要**：「プロジェクト → シーズン → 話」で構成。長編小説をインポートして複数話の草稿に自動分割でき、プロジェクト全体のバックアップ書き出しにも対応します。
* **プロジェクトリソースと世界観**：単話制作の前にキャラクター／シーン／小道具のリソース、および地図・地域・場所・音楽スタイルなどの世界観アンカーを蓄積します。これらの情報は以降のストーリー、アセット、カット生成に継続的に注入されます。

### Phase 01: ナラティブ設計

* **構造化脚本生成**：あらすじ、小説の抜粋、単話のアイデアを入力すると、AI がキャラクター、シーン、小道具、カットなどを構造化して分解します。
* **設定駆動生成**：言語、目標尺、ビジュアルスタイル、モデル構成を設定し、以降の全パイプライン出力を統一的に制御します。
* **AI 続き生成と手動調整**：脚本本文、キャラクターの視覚記述、カットのアクション、セリフ、プロンプトの続き生成・書き換え・項目別の手動編集が可能です。
* **全自動プラン事前審査**：本格的な一括生成の前に全自動制作プランを提示し、カットごとに「九分割絵コンテ」か「開始／終了フレーム」のどちらの経路を使うかを選べます。

### Phase 02: 一貫性アセット

* **キャラクター一貫性キャスティング**：各キャラクターの標準参照画像を生成し、ワードローブシステムで複数衣装にわたる同一性を維持します。
* **シーン／小道具のアセット化**：主要シーン画像だけでなく、再利用可能な小道具に独立したプロンプト、参照画像、形状参照を構築します。
* **アセットライブラリ再利用**：プロジェクトリソースまたはプロジェクト横断のアセットライブラリからキャラクター、シーン、小道具を選択し、重複構築を削減します。
* **欠損アセットの一括補完**：キャラクター、シーン、小道具の不足画像をワンクリックで補完し、以降のカット制作に安定したコンテキストを用意します。

### Phase 03: カット制作

* **グリッド型カットワークベンチ**：すべてのカットを一覧管理し、カットごとにナラティブアクション、キャラクター、シーン、小道具のコンテキストを確認できます。
* **キーフレーム精密制御**：Start Frame／End Frame の生成、アップロード、継承、編集に対応し、カットの開始・終了状態の制御を強化します。
* **九分割絵コンテプレビュー**：9 つの候補アングルを先に生成し、全体画像または 1 マスの切り出しを最初のフレームとして選択して、構図を素早く確定できます。
* **コンテキスト認識生成**：カット生成時に現在のシーン画像、キャラクターの衣装参照、小道具参照を自動的に読み込み、「連続性の破綻」を大幅に削減します。
* **デュアル動画経路**：単一画像の Image-to-Video と、開始／終了フレーム補間の両方に対応します。

### Phase 04: 完成品納品

* **タイムラインプレビューとレンダリング追跡**：カットの完成度、ラフ編集タイムライン、レンダリングログをリアルタイムで確認できます。
* **CutOS 風 AI ラフ編集**：内蔵タイムラインエディタで、生成済みカットの並べ替え、トリミング、フィルター、書き出し前チェックが可能です。
* **多様な納品形式**：マスター動画、クリップ圧縮ファイル、ソース素材を書き出し、Premiere／Resolve などのポストプロダクションに引き継げます。
* **話数レベルバックアップ**：現在の話数データのインポート／エクスポートに対応し、デバイス間の移行や共同作業を容易にします。

### Phase 05: プロンプト管理

* **一元検索と編集**：テンプレート、キャラクター、シーン、小道具、キーフレーム、動画のプロンプトをまとめて確認できます。
* **バージョンロールバック**：プロンプトの編集履歴を保持し、古いバージョンへ素早く戻せます。
* **工程横断のデバッグ**：結果が不安定なとき、このページに戻って上流のプロンプト問題を特定・修正できます。

| 方法 | 説明 | 向いている用途 |
|------|------|----------------|
| **オンライン版** | ブラウザで [director.tree456.com](https://director.tree456.com/) にアクセスするだけ。インストール不要 | 素早い試用、いつでも利用、常に最新 |

| **デスクトップクライアント** | Windows 10+／macOS 11+、Electron 製、インストーラー約 122MB、すぐ使える | オフラインでの脚本編集、ローカル作業 |

### 公開版の実行形態

* **提供方法**：公開リポジトリは主に説明ドキュメント、`docker-compose.yaml`、公式 Docker イメージの配備入口を提供し、ソースコードの継続同期は行いません。
* **実行方法**：公式 Docker イメージで完全なワークベンチを起動し、ブラウザから利用できます。フロントエンドのビルドや環境の手動構築は不要です。
* **モデル接続**：テキスト、画像、動画モデルはデフォルトで AntSK API を通じて統合接続され、ワンストップで設定・呼び出しできます。
* **データ保存**：プロジェクトデータは主にローカルブラウザ環境に保存され、個人制作と軽量な共同作業に適しています。バージョンアップは公式イメージのリリースに準じます。

## よくある質問（FAQ）

### BigBanana は無料ですか？隠れた課金はありますか？

ソフトウェア自体は無料です。Docker イメージ、デスクトップクライアント、オンライン版のいずれも、ライセンス料・サブスクリプション料・機能解放料はかかりません。**AI モデルの呼び出し費用は各プロバイダーが実際の利用量に応じて課金します**。各プラットフォームで登録し、API Key を設定してください。低コストで試すなら、無料枠の大きいモデル（DeepSeek など）から始めるのがおすすめです。

### なぜ今後のバージョンはソースコードを公開しなくなったのですか？

無断転載、クレジットなしの流用、さらには悪意ある再ホストが繰り返されたため、今後の機能更新は公式 Docker イメージのみで提供し、ソースの公開同期は行いません。現在の公開リポジトリは説明ドキュメント、`docker-compose.yaml`、過去バージョンの参照として残ります。**商用版のお客様には引き続き完全なソースコードを提供します。**

> これは受け身的なメンテナンス方針の調整であり、オープンソースコミュニティの放棄ではありません。完全なライセンス条項と商用連携の方法は下部の「ライセンス」をご覧ください。

### 生成したコンテンツは商用利用できますか？著作権は誰に？

BigBanana で制作したコンテンツの**著作権は制作者に帰属します**。ただし 2 点ご注意ください：
1. 本プロジェクトのコードは **CC BY-NC-SA 4.0** ライセンスです。**商用利用には許諾が必要です**（antskpro@qq.com までご連絡ください）。
2. 各 AI モデルプロバイダーは生成コンテンツの利用条件をそれぞれ定めています（OpenAI は商用可、Google は特定の制限ありなど）。商用前に該当プロバイダーの利用規約をご確認ください。

### AntSK API は必須ですか？他のモデル経路に変更できますか？

公開版はデフォルトで AntSK API を通じて統合接続され、**クロスモデル互換**（テキスト／画像／動画を一括設定）と**価格優位性**（公式チャネルより 80% 以上安価）が特長です。他の経路を希望する場合は、OpenAI や Google の公式サービスを自由に利用できます。これは当然かつ尊重される選択です。プライベートなモデルゲートウェイや深いカスタマイズが必要な場合は、商用版ソースコード提供を基に適応できます。

### データはどこに保存されますか？安全ですか？

プロジェクトデータは主に**ローカルブラウザ環境（IndexedDB）**に保存され、サーバー側への依存はありません。脚本、キャラクター設定、生成画像は優先的にローカルデバイス内に留まります。オリジナルキャラクターを育成中で、まだ IP を公開していないクリエイターにとって特に重要です——**あなたのキャラクター資産は、あなたの手元にあるべきです。**

> 注意：ローカル保存は個人制作と軽量な共同作業に適しています。複数人によるリアルタイム共同作業が必要な場合は商用版をご検討ください。

### 初心者でも使えますか？学習コストは高いですか？

BigBanana は**産業用の制作ツール**であり、ワンクリック生成の玩具ではありません。絵を描けたり動画を編集できたりする必要はありませんが、ある程度の脚本への意識と、絵コンテやセリフを軽く調整する意欲が必要です。「ボタン一つで即バズる作品」を求めるのであれば、このツールは向いていません。

### 対応 OS と動作要件は？

**Windows 10 以上**および **macOS 11 以上**に対応し、Electron 製のデスクトップクライアントです。インストーラーは約 122MB で、追加のランタイムや依存ライブラリのインストールなしにすぐ使えます。AI モデル API の呼び出しには安定したネットワーク接続が必要です。加えて、**オンライン版**（ブラウザ）と **Docker 配備**というインストール不要の方法も利用できます。

### デフォルトの画風は？リアル系に変更できますか？

デフォルトは**アニメ／イラスト調**で、モーションコミックや短編動画マンガに適しています。プロジェクトの「ビジュアルスタイル」設定と各キャラクター／シーンの「視覚プロンプト」を変更することで方向性を調整でき、リアル、サイバーパンク、水彩、油絵、ピクセルアートなどに対応します。最終的な仕上がりは選択した画像生成モデルにも依存します。

### 1 話の制作にどれくらい時間がかかりますか？

尺と複雑さによります。**5 分・10 カット**の短編モーションコミックの場合、AI ディレクターチームは通常 **1〜2 時間**で全工程を完了します：脚本とキャラクター設定に約 20 分、絵コンテ設計に約 15 分、画像生成に約 30 分、動画生成に約 20 分、吹き替えに約 10 分。各段階で人による確認と調整が可能です。慣れたユーザーが 5 分の 1 話を実際に仕上げる時間は、工程の受け渡しを含めて 2〜3 時間程度です。

## なぜ AntSK API なのか？

## クイックスタート

1. **アカウント／キーの設定**：初回起動時にオンボーディング、アカウントセンター、またはモデル設定で AntSK API Key／Token を入力します。[**今すぐ購入**](https://api.antsk.cn)
2. **プロジェクト作成**：プロジェクトハブで新規作成。以降のシーズン、話数、アセット、納品物はすべてこのプロジェクトに集約されます。
3. **プロジェクトの枠組み構築**：プロジェクト概要でシーズン／話を手動作成するか、長編小説をインポートして複数話の草稿に自動分割します。
4. **プロジェクトリソースの補充**：キャラクター、シーン、小道具、世界観を整理し、以降の各話で統一設定を再利用できるようにします。
5. **Phase 01 ナラティブ設計へ**：構造化脚本を生成し、キャラクター、アクション、セリフ、プロンプトを手動校正します。一括制作の場合は「全自動モード」プランを先に確認します。
6. **Phase 02／03 へ**：一貫性アセットを先に整え、カット制作で最初のフレーム、最後のフレーム、九分割絵コンテ、動画クリップを生成します。
7. **Phase 04／05 へ**：完成品納品でプレビュー、ラフ編集、書き出し、バックアップを行います。生成品質を全体修正したい場合はプロンプト管理に戻ります。

## デプロイ

### イメージ配備（公開版）

```bash
# 1. 配備ファイルを取得
git clone https://github.com/shuyu-labs/BigBanana-AI-Director.git
cd BigBanana-AI-Director

# 2. 公式イメージを起動
# 初回起動時に必要な公式イメージが自動的に取得・起動されます
docker-compose up -d

# 3. アプリにアクセス
# ブラウザで http://localhost:3005 を開く

# ログを確認
docker-compose logs -f

# サービスを停止
docker-compose down
```

### 公式イメージの更新

```bash
# 最新の公式イメージを取得してコンテナを再作成
docker-compose pull
docker-compose up -d --force-recreate
```
